WILDLIFE FLIGHT ART - 17 images to draw in your ChatGPT "CapyIsland" project
=============================================================================

BEFORE YOU START
  Add one more source to the project: ArtSource/Wild_Bird_sparrow_Sheet.png
  (a finished sheet, so ChatGPT sees exactly what layout we want).

FOR EACH ONE BELOW
  1. Start a NEW chat inside the CapyIsland project (keeps each one clean).
  2. Paste the prompt (the long paragraph). Nothing to attach: it names its source files.
  3. Check the result:
       - the same creature drawn TWICE, side by side, the same size
       - LEFT = wings up, RIGHT = wings down
       - facing the same way as its reference picture
       - transparent background, no ground, no shadow, the two drawings not touching
     If not, say "try again, keep it exactly like the reference" or start a fresh chat.
  4. Download the PNG and save it in the project's ArtSource folder with the "Save as" name.

WHEN DONE (some or all)
  Tell Claude. It cleans the edges, splits each sheet into its two frames and puts them in the game.

Already done, skip these: gull, sparrow, robin, egret.
